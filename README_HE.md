# BPI V72 — חבילת תיקון בטוחה לנספחים
***סיפורים שסיפרתי לאימי***

החבילה הזו מחליפה את חבילת התיקון הקודמת.

## מה היא מתקנת

2. תת־הכותרת מקבלת עיצוב אמיתי של subtitle:
   - קרובה לכותרת
   - ממורכזת
   - סמי־בולד
   - איטליק
   - גודל מובחן
   - צבע משני ולא טקסט רגיל
3. התמונות ממורכזות בכל HTML רלוונטי: שער, תמונות סיפורים, figures ו־image-frame.
4. DOCX מתוקן בצורה בטוחה בתוך הקובץ, בלי לבנות אותו מחדש ובלי לאבד תמונות.

## מה היא לא עושה בכוונה

- לא מריצה pandoc.
- לא מריצה weasyprint.
- לא בונה PDF מחדש.
- לא מחליפה תמונות בתיאורים.
- לא מוחקת/משנה שמות/מחליפה קבצי תמונה.
- לא משנה תוכן סיפורים.

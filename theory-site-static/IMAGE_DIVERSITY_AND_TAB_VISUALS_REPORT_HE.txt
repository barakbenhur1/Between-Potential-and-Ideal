# דוח תיקון תמונות, אחידות וגיוון — 21.05.2026

## מה תוקן

### 1. גיוון תמונות קטנות
הבעיה: התמונות הקטנות חזרו על עצמן יותר מדי, בעיקר בכרטיסים פנימיים ובטאבים.
התיקון: הוחלפו התמונות הקטנות בנכסים ייחודיים יותר לפי משמעות הכרטיס:
- ליבה: שער / דרך אל אור.
- עדות: חצר שקטה, דמויות, נוכחות וסיפור.
- יישום: נוף גאומטרי / מבנה / מעבר בין רעיון לצורה.
- AI כעדות: דמות מול שער/מראה מופשטת.
- קבצים / נספחים: ארכיון, מדפים ומסמכים.
- מתודולוגיה / לפני הקריאה: נהר, סירה, דרך וניווט.
- ביקורת / התנגדויות: איזון, בחירה ושתי דרכים.
- מקורות / סייג מדעי: חדר לימוד, ספרייה, אסטרונומיה ומקורות.

הצדקה: כל תמונה קטנה משמשת עכשיו כסימן חזותי מקומי ולא כקישוט חוזר.

### 2. אחידות תמונות גדולות בין הטאבים
הבעיה: חלק מתמונות הטאב הגדולות נראו גבוהות ורחבות, וחלק נראו כמו מלבן צר.
התיקון: הוחל כלל CSS אחיד לכל `.tab-visual.compact-section-visual`:
- אותו יחס רוחב/גובה.
- אותו גובה מינימלי ומקסימלי.
- אותו object-fit.
- אותו radius.
- אותה התנהגות במובייל.

הצדקה: התמונות עדיין שונות בתוכן, אבל יושבות באותו משקל עיצובי בכל עמוד.

### 4. שמירה על שפת האתר
כל התמונות החדשות נשמרות באותו עולם חזותי:
- בלי טקסט בתוך תמונות.
- טקסטורת נייר.
- כחול עמוק / זהב / קרם / ירוק עמום / כתום רך.
- איור שקט, מופשט, לא דרמטי.
- לא סצנה סיפורית מדי כאשר מדובר בטאב אתר.

# Translation batches

The Klingon and Neo-Quenya editions are built in reviewable batches. A later batch may not silently change terminology approved in an earlier batch.

## Batch 0 - terminology and infrastructure

- language configuration;
- inventory and parity audits;
- canonical source format;
- five-format document builder;
- shared language-menu specification;
- core terminology registry.

## Batch 1 - entry path

- home page;
- summary;
- glossary;
- potential / ideal / optimal concepts page;
- core page;
- central `between-potential-and-ideal` document package in HTML, PDF, DOCX, MD and TXT.

## Batch 2 - method and witness

- methodology;
- witness;
- AI as witness;
- editorial and tightened document packages;
- editorial report package.

## Batch 3 - application and critique

- application;
- critique;
- sources;
- potential extensions;
- related long-form packages.

## Batch 4 - AI texts

- AI landing page;
- What AI Believes;
- When I Am Also You;
- Reverse Turing Conversation;
- all corresponding five-format packages.

## Batch 5 - literary appendices

- stories landing page;
- Stories Before Thought collection;
- The Nauseating Truth;
- A Mistake Always Returns;
- all protected story endings, images, captions and five-format packages.

## Batch 6 - public integration

- accessible four-language menu;
- same-page language mapping;
- canonical and hreflang links;
- sitemap and search index;
- Files pages and download labels;
- mobile and desktop visual QA;
- language-residue QA;
- final release guard.

Both target languages remain hidden until Batch 6 passes without blockers.

# חבילת הפצה מלאה - בין פוטנציאל לאידיאל

זוהי חבילת ההפצה המסודרת והמלאה של ההרחבה: אתר מלא, מסמכי תאוריה, פרקים מפוצלים, מסמכים משולבים, דוחות, מפות, פרומפט ומקורות.

## מבנה התיקיות

- `01_complete_website_archive` - האתר/הארכיון המלא.
- `02_full_theory_documents` - מסמכי התאוריה המרכזיים בעברית ובאנגלית.
- `03_split_chapters` - כל פרקי היישום מפוצלים. לכל פרק יש TXT, MD, DOCX ו־PDF.
- `04_combined_expansion_documents` - מסמכי הרחבה משולבים בעברית, באנגלית ובדו־לשוני.
- `05_reports_and_maps` - דוחות QA, מפת AI, מפת אופקים, דוח הפצה ורשימת קבצים.
- `06_prompts_and_sources` - הפרומפט המלא ששימש לביצוע.
- `07_original_existing_documents_preserved` - מסמכים קיימים שנשמרו מהארכיון.

## ספירת פורמטים

- DOCX: 36
- PDF: 43
- MD: 54
- TXT: 71

## איך להשתמש

לקריאה מהירה: פתח את `04_combined_expansion_documents`.
לעריכה: השתמש בקובצי DOCX.
לניהול גרסאות/גיטהאב: השתמש בקובצי MD.
להפצה וקריאה נקייה: השתמש בקובצי PDF.
לעבודה באתר: פתח את `01_complete_website_archive/Between-Potential-and-Ideal-main/theory-site-static/index.html`.

# V31 — תיקון והרחבה ממוקדים על בסיס V30

בוצע:

1. הרחבת הפרקים הראשונים
- הורחבו שלושת הפרקים הראשונים בתאוריה הפילוסופית בעברית ובאנגלית.
- הורחבו שלושת הפרקים הראשונים בגרסה הלוגית בעברית ובאנגלית.
- ההרחבות נוסחו בזהירות: ללא טענות חדשות שחורגות מן התאוריה, ללא הפרת הערות מבקרים, וללא הפיכת מטאפורות לטענות מדעיות.
- עודכנו HTML / MD / PDF / DOCX בקבצים המרכזיים.

2. קבצי מקור
- נוסף אזור “קבצי מקור מלאים” בעברית ובאנגלית.
- נוספו קישורים מסודרים לכל הפורמטים המרכזיים: HTML / PDF / DOCX / MD / TXT לפי הצורך.
- נבדק שאין כפתור PDF כפול במקום שבו צריך MD.

3. גרסה לוגית
- עמוד השער של הגרסה הלוגית כולל עכשיו את התמונה הייחודית של הגרסה הלוגית.
- התמונה הוכנסה בלי מסגרת/רקע לבן מיותר.
- ה-PDF הלוגי בעברית ובאנגלית נבנה מחדש עם השער והתמונה.

4. נספחים וסיפורים
- נוסף איור לעמוד השער של אוסף “סיפורים לפני המחשבה”.
- הוסר הטקסט המיותר “Between Potential and Ideal” משער הנספחים.
- הוסרו כפתורי הפורמטים משער ה-PDF של הנספחים כדי שלא יופיע שוב PDFDOCXMDTXT.
- תמונות הסיפורים הוחזרו להיות ממורכזות וגדולות יותר.
- עודכנו HTML / PDF / DOCX של אוספי הסיפורים בעברית ובאנגלית.

5. עדות / סיפורים לפני המחשבה
- כפתור “טעות לעולם חוזרת” יושר עם שורת הכפתורים/כרטיסים האחרים באמצעות CSS.
- הכרטיסים הוגדרו כ-flex column כדי ששורת הכפתורים תשב בתחתית בצורה עקבית.

6. ניקוי שם האתר
- הוסר מופע שעלול להיראות כ־BetweenPotentialandIdeal ללא רווחים.
- בלוגו/כותרות הרלוונטיים נשמרת כתיבה עם רווחים: Between Potential and Ideal.

בדיקות:
- כל בדיקות V31 עברו.
- אין כפתורי PDF כפולים ב-download rows שנבדקו.
- ההרחבות קיימות ב-HTML/PDF/DOCX.
- שער הנספחים מכיל תמונה.
- שער הגרסה הלוגית מכיל תמונה.
- כפתורי פורמט לא מופיעים כשורת PDFDOCXMDTXT בשער ה-PDF של הנספחים.

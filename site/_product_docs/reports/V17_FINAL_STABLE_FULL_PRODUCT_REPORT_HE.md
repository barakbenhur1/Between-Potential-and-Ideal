# V17 סופי — מוצר מלא יציב

בוצע:
- החזרת CSS יציב והסרת שכבות הטלאים המאוחרות ששברו את האתר.
- תיקון דבר המחבר בעברית ובאנגלית: טקסט חי, ללא דאבל-עיגול וללא תווית פונט גלויה.
- רווחים בין דפי המסמך בתצוגת HTML בלבד, בלי לפגוע בדפי האתר הציבוריים.
- תוכן העניינים אינו מכריח עמוד חדש אחרי סופו.
- פתיחת פרק אינה מתחילה עמוד חדש בכוח, אבל נשמרת כיחידה אחת.
- PDF עברית ואנגלית עודכנו נקודתית כך שהערת הקריאה תיכנס לעמוד סיום תוכן העניינים במקום להשאיר עמוד כמעט ריק.
- המוצר נארז כמוצר מלא, לא רק כקבצי תיקון.

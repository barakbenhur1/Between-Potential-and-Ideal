# דוח ניקוי ותיקון V8

בוצע על בסיס V7 המלא שהועלה בשבעה חלקים.

תוקן:
- דבר המחבר בעברית נשאר טקסט חי, ממורכז בציר X ובציר Y.
- הפונט העברי מוגדר כ־Gveret Levin ראשון, עם fallback רגיל בלבד אם הפונט לא מותקן.
- הוסרו כללי CSS שכפו פתיחת כל פרק בעמוד חדש.
- פתיחת פרק נשמרת כיחידה אחת: כותרת, תת־כותרת, תמונה ותיאור תמונה.
- שער, דבר המחבר ותוכן העניינים נשמרים כעמודים נפרדים.
- נוספו רווחים תקינים בין עמודים בתצוגת HTML.
- תוקנו שמות סיפורים באנגלית שהופיעו בתוך אוסף הסיפורים בעברית.
- נוקו קבצי ביניים/QA/טלאים/חלקי סיפורים ופרקים שכבר שולבו במסמכים הקנוניים.

לא נמחק תוכן קנוני מהמסמכים המרכזיים, מאוספי הסיפורים או מקובצי האתר הנדרשים.

קישורים פנימיים לקבצים שנוקו הוסרו מדפי האינדקס כדי למנוע לינקים שבורים.

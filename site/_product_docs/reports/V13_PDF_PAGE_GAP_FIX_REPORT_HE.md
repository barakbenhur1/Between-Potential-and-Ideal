# V13 תיקון רווח בין דפי PDF

בוצע תיקון נקודתי ל־PDF בעברית ובאנגלית:

- נוספה מסגרת/רווח פנימי לבן בחלק העליון והתחתון של כל עמוד PDF.
- התוכן לא עבר רסטריזציה ולא הוחלף לתמונה.
- הדאבל־עיגול בדבר המחבר כבר לא קיים בעמוד 2 של PDF עברית/אנגלית.
- צורפו גם HTML / MD / DOCX / CSS הנחוצים כדי לשמור תאימות בין הפורמטים.

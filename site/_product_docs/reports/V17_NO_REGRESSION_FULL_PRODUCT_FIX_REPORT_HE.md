# V17 — תיקון מלא ללא רגרסיה מכוונת

בוצע על בסיס המוצר הקיים, עם החזרת CSS יציב והסרת שכבות הטלאים המאוחרות ששברו את האתר.

מה תוקן:
- הוחזר `styles.css` יציב מהבסיס הקודם במקום שכבות V8-V14 ששברו ניווט/פריסה.
- הוסר CSS ניסיוני מאוחר מתוך קבצי HTML.
- דבר המחבר בעברית ובאנגלית נשאר כטקסט חי, ללא דאבל עיגול וללא תוויות פונט.
- באתר/HTML יש רווחים בין דפי המסמך, אבל רק בדפי מסמך ולא בדפי האתר הציבוריים.
- שער ודבר המחבר נשמרים כעמודים נפרדים בהדפסה/PDF.
- תוכן העניינים אינו מכריח מעבר עמוד אחרי סופו; אם יש מקום, פתיחת הפרק יכולה להתחיל באותו עמוד.
- פתיחת פרק נשמרת כיחידה אחת: כותרת, תת־כותרת, תמונה ותיאור תמונה.
- לא כל פרק מתחיל עמוד חדש בכוח.

הערה: התיקון מכוון למנוע רגרסיות באתר על ידי scope ל־body שאינו public-page.

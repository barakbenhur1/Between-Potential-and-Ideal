# V24 — הקשחת תיקון סופית

בוצע:
- הוספת CSS סופי שמונע רקע שחור בעמודי האתר הציבוריים.
- הוספת CSS inline לכל HTML רלוונטי כדי למנוע בעיות cache או סדר טעינה.
- סימון עמודי נספחים ב-class מתאים כך שתמונותיהם יוגבלו בפועל גם כשיש inline style על התמונה.
- הגבלת תמונות נספחים/סיפורים/פרקים לגודל סביר שלא יוצא מגבולות הכרטיס/העמוד.
- תיקון stories.html כך שיש תת-כותרת עברית ואנגלית.
- תיקון כרטיסי עדות וסיפורים נשמר מהשלבים הקודמים.
- בניית PDF/DOCX של אוספי הסיפורים מתוך HTML זמני ללא כפתורי download, כדי למנוע PDFDOCXMDTXT במסמכים.
- נשמר A Few Strings and a Knot, ואין Several Strings and a Knot בקבצי היעד.

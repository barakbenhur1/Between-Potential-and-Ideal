# V30 — תיקון סופי

בוצע בשלב זה:

1. דף הבית בעברית ובאנגלית הוחזר לבסיס היציב הישן.
   - `index.html` ו-`en.html` שוחזרו.
   - נוסף `styles-home-original.css` כדי שדף הבית לא יידרס יותר על ידי תיקוני מסמכים.
   - תמונת הפתיחה והכפתורים המקוריים חוזרים לפי בסיס V17.

2. הגרסה הלוגית:
   - נוסף שער לגרסה הלוגית בעברית ובאנגלית.
   - ה-PDF הלוגי נבנה כך שהשער הוא עמוד ראשון עצמאי.
   - תוכן העניינים מתחיל בעמוד הבא.
   - ה-HTML/MD עודכנו בהתאם.

3. דבר המחבר בגרסה הפילוסופית:
   - נבנה מחדש בעיצוב נקי.
   - המלבן הוקטן וממורכז.
   - הטקסט ממורכז.
   - הוסרו התוויות והכפילויות שיצרו דאבל-עיגול/כפתור.
   - עמודי PDF בעברית ובאנגלית הוחלפו בעמוד נקי ומרונדר.

4. פונט עברי:
   - נוספה טעינת web-font של `Gveret Levin` דרך CSS.
   - נשאר fallback תקין ל-`Noto Sans Hebrew`, `Arial`, `sans-serif`.
   - לא צורף קובץ פונט מקומי.

5. רקעים שחורים:
   - נוטרלו כללי רקע שחור בקבצי המסמך הקריטיים.
   - נוספו כללים שמחזירים מסמכים לרקע בהיר.

6. פורמטים:
   - עודכנו HTML / MD / PDF.
   - DOCX הוחזרו לגרסה היציבה כדי להימנע מרגרסיה שנוצרה בהמרת DOCX מחדש.

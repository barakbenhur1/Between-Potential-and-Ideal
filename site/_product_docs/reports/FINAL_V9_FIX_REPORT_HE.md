# דוח תיקון V9 — תיקוני פריסה אמיתיים

בוצע על בסיס V8 המחודש, עם תיקון בפועל של הבעיות שדווחו:

- דבר המחבר בעברית ובאנגלית הוגדר כעמוד מלא וממורכז בציר X ובציר Y.
- דבר המחבר נשאר טקסט חי, לא תמונה.
- הפונט בעברית נעול ל־Gveret Levin AlefAlefAlef / Gveret Levin כאשר זמין, ולאחר מכן fallback רגיל בלבד: Noto Sans Hebrew / Arial / sans-serif.
- הוסרו/הוחבאו תמונות author-note ישנות כדי שלא ידרסו את הטקסט החי.
- נוספו רווחים חזותיים בין עמודים/מקטעי עמוד במסך.
- בוטלה פתיחת כל פרק בדף חדש.
- פתיחת פרק נשמרת כיחידה אחת: כותרת, תת־כותרת, תמונה ותיאור תמונה.
- שער, דבר המחבר ותוכן העניינים נשארים בדפים נפרדים ב־PDF/הדפסה.
- תוקנו שאריות שמות באנגלית בתוך קבצי עברית.

בדיקות שבוצעו: בדיקת תקינות ZIP, בדיקת קישורים פנימיים, ורינדור דפי PDF/PNG מייצגים לשער, דבר המחבר, תוכן עניינים ופתיחת פרק.

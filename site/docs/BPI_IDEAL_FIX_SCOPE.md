# מה יושם ומה עדיין דורש בדיקה חיה

הסקריפט מיישם תיקונים שמסוכנים פחות וניתנים לביצוע אוטומטי:
- נגישות בסיסית.
- alt לתמונות.
- תיקון קופסאות תמונה.
- תיקון תוכן עניינים במסמכי התאוריה בלי לשנות טקסטים שמורים.
- התחלה מומלצת.
- metadata בסיסי.
- sitemap/robots.

דברים שעדיין צריך לבדוק ידנית באתר החי:
- האם Render מציג את commit האחרון.
- האם כפתורי Open Discussion/feedback מובילים ליעד הרצוי.
- האם יש עמודים שמפנים ל-redirect.html בכוונה או כבאג.
- האם PDF/DOCX regenerated אחרי השינוי.
- האם התמונות כבדות מדי וצריך להמיר ל-WebP.
- האם יש פערי תוכן אמיתיים בין עברית לאנגלית שאינם ניתנים לתיקון אוטומטי בלי עריכה אנושית.

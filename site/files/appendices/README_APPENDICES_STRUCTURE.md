# Appendices structure

Canonical public appendix files are kept at their existing paths to avoid breaking website links, Render deployment, or direct downloads.

Current structure:

- `stories-before-thought-hebrew-rtl.*` — Hebrew collection of all stories.
- `stories-before-thought-english.*` — English collection of all stories.
- `assets/` — story images used by the story collections.
- `mistake-repeats/` — the separate “A Mistake Always Returns / טעות לעולם חוזרת” appendix package.

Removed from this folder:
- standalone single-story files for stories already included in the main story collections.
- old partial/duplicated story exports.

The removed content is not lost: those stories remain inside the canonical story collection files in HTML, PDF, DOCX, MD, and TXT.

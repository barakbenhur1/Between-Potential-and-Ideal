# V31 — הרחבת פרקים ראשונים ותיקון קבצי מקור

בוצע:
- הורחב פרק א׳ בגרסה הפילוסופית בעברית ובאנגלית.
- הורחב הפרק הראשון בגרסה הלוגית בעברית ובאנגלית.
- ההרחבות נשארות בתוך גבולות התאוריה הקיימת: פוטנציאל/אידיאל/אופטימלי, אי־הצדקת סבל, הפרדה בין מטאפורה לטענה מדעית, ופתיחות לביקורת.
- עודכנו HTML / MD / DOCX / PDF עבור שני סוגי התאוריה בשתי השפות.
- תוקן אזור קבצי המקור בעמודי היישום בעברית ובאנגלית: הרשימה כבר לא ריקה ומכילה קישורי TXT / MD / DOCX / PDF לפרקי ההרחבה.
